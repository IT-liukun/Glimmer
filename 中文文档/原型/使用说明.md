# 怎么打开微光原型

这个原型不是网页。在 Cursor 里打开 Canvas 文件，才能点击页面。

## 它是什么

`glimmer-prototype.canvas.tsx` 是 Cursor Canvas 的源码。

浏览器打不开它。`npm start` 也打不开它。

Cursor 只渲染你这台电脑上 Canvas 目录里的那一份。仓库里的同名文件是给 Git 带走的副本。

换一台电脑时，先把仓库里的副本拷进那台电脑的 Canvas 目录。再在 Cursor 里打开拷过去的文件。

## 1. 用 Cursor 打开本仓库

1. 安装 Cursor，并登录。
2. 克隆本仓库。
3. 用 Cursor 打开仓库根目录。这个文件夹叫 `Glimmer`，里面有 `中文文档`。

打开上一级文件夹，或者只打开 `中文文档`，Canvas 目录会对不上。

这个文件只从 `cursor/canvas` 引入组件。不用安装依赖。

## 2. 找到本机的 Canvas 目录

Cursor 给每个已打开的工作区单独准备一个目录。这个目录不在 Git 里。路径会随操作系统、用户名和仓库位置变化。

在这台电脑上，目录是：

```text
C:\Users\liuk\.cursor\projects\c-ekuinlu-workspace-Glimmer\canvases\
```

换一台电脑时，先用 Cursor 打开仓库。再到用户目录的 `.cursor\projects` 里，找名字里带有工作区路径的文件夹。用里面的 `canvases`。

Windows PowerShell：

```powershell
Get-ChildItem "$env:USERPROFILE\.cursor\projects" -Directory | Where-Object { $_.Name -like "*Glimmer*" }
```

macOS 或 Linux：

```bash
ls ~/.cursor/projects | grep -i Glimmer
```

还没有这个文件夹时，先在 Cursor 里打开一次本仓库，再查。不要自己新建这层目录。

## 3. 把仓库里的副本拷进去

源文件：

```text
中文文档/原型/glimmer-prototype.canvas.tsx
```

目标文件名仍是 `glimmer-prototype.canvas.tsx`。直接放在 `canvases` 里面。不要再套子文件夹。

Windows PowerShell。把目标路径换成上一步查到的目录：

```powershell
Copy-Item -Force ".\中文文档\原型\glimmer-prototype.canvas.tsx" "$env:USERPROFILE\.cursor\projects\<工作区目录名>\canvases\glimmer-prototype.canvas.tsx"
```

macOS 或 Linux：

```bash
cp "中文文档/原型/glimmer-prototype.canvas.tsx" ~/.cursor/projects/<工作区目录名>/canvases/glimmer-prototype.canvas.tsx
```

也可以在这个工作区的 Cursor 对话里说「按使用说明打开微光原型」。助手会把仓库里的文件写到正确的 Canvas 目录。

## 4. 打开页面

在 Cursor 里打开 Canvas 目录中的那个文件。页面出现在聊天旁边。可以切换访客、捐款人、管理员，也可以在各页面之间点选。

直接打开 `中文文档/原型/glimmer-prototype.canvas.tsx`，只能看到源码。看不到可操作的页面。

页面是空白的，或 Cursor 没有把它当成 Canvas 时，检查两件事：

- 文件是不是直接放在 `canvases` 这一层
- 文件名是不是以 `.canvas.tsx` 结尾

## 5. 改完以后怎么同步

Canvas 目录里的文件不在 Git 中。

- 在页面上改过之后，提交前把 Canvas 目录里的文件拷回 `中文文档/原型/glimmer-prototype.canvas.tsx`。
- 从 Git 拉到别人的修改后，再按第 3 步拷一次。本机页面才会更新。
