# 微光原型图描述文档

本文件从《微光产品需求文档》和《微光用户用例手册》抽出各页面上有什么：字段、顺序、查询、空状态和按钮。业务规则仍以产品需求文档为准，操作走到哪一页仍以用户用例手册为准。

通用排版（查询草稿、分页条、卡片、折叠文字）以 `.cursor/rules/prototype-layout.mdc` 为准。下面只写每个页面用了哪一种。

## 1. 两套外壳

用户端是宽 360px 的手机。页顶「微光」居中。底部三个标签始终在：「项目」「善款」「我的」。打开时停在「项目」，当前标签高亮。列表、详情和登录过程中标签不消失。返回在左上。内容限制在手机宽度内，不出现横向滚动条，一行放不下时换行。

管理端有桌面和移动两种布局。桌面用侧栏，六项并列：项目、善款、受益人、捐款身份、导入文档、管理员。移动端从宽度 360px 起，底部是「项目」「善款」「受益人」「其他」。「其他」默认折叠，展开后是「捐款身份」「导入文档」和「管理员」。从用户端「我的」的「进入后台」进入后，首先是项目列表。返回在左上。操作按钮靠右，主操作在最右。桌面表格和底栏都限制在页面宽度内，放不下时换行，不出现横向滚动条。

## 2. 反复出现的样子

### 公开称呼

| 身份情况 | 称呼 |
| --- | --- |
| 匿名 | 匿名捐款人 |
| 未匿名，对外展示名有内容 | 对外展示名 |
| 未匿名，对外展示名为空 | 「{平台}捐款人」 |

用户端「善款」页和项目详情的善款都不展示个人说明。

### 公开项目一条三行

第一行：项目名称居左，状态标签紧跟名称，开始日期居右。用户侧只有状态，不显示「超支」。第二行：善款合计、开销合计。第三行：「x 名受益人」。结余、项目编号不在这一侧。

### 管理端项目一条（移动卡片）

与公开三行相同，并多出管理字段。状态后面，结余小于 0 时紧跟「超支」。名称下方靠左是项目编号。第二行另有结余。桌面端改用表格。

### 公开善款一张卡片

第一行：公开称呼在左，绑定状态紧跟名称，捐款日期在右。其下：金额、平台。不展示个人说明。项目详情里的「善款」不再重复项目名称，也不展示「已绑定」标签。善款捐赠明细在下方增加已绑定项目：有有效绑定时为项目名称，可点进项目；未绑定为「尚未安排到具体项目」，不能点。某一身份的捐款列表不用这张卡片。

### 详情里关联记录过多

用户端项目详情，以及管理端移动端的进展、善款、开销，不筛选、不分页，按日期倒序。进展默认只展示前 2 条，每次再展示 2 条。善款和开销默认只展示前 5 条，每次再展示 5 条。多于默认条数时，下方居中显示没有边框的「查看更多」加该段标题。已经多看过、且仍有未展示记录时，「收起更多」和「查看更多」并排居中，收起在左。全部展示后只留下「收起更多」，点它回到默认条数。管理端桌面这三段全部展示，不折叠。

### 列表查询

桌面端：主键、名称、分类直接展示；时间和其他字段收在「更多条件」，默认折叠。点「查询」才生效，并从第 1 页重取。「清除」在左，「查询」在右。表格，每页可选 10、20、50。底栏一行：共 N 条、N条/页、上一页、附近页码和首页末页、下一页、前往页码。总数为 0 时只显示「共 0 条」。

移动端和用户端：展示名称和分类。分类的枚举用按钮平铺，同一时间只选中一项，改完即查。没有名称和分类时改为展示主键，同样改完即查。不显示「清除」和「查询」。卡片，滑到底按每页 10 条继续加载，底部只显示共 N 条。

## 3. 用户端

### 「项目」

查询：项目名称；状态按钮为「全部」「进行中」「已完成」「已关闭」。默认按开始日期倒序。每一条用公开项目三行。没有项目时说明当前没有公开项目。没有新建、编辑、绑定、作废。受益人只有人数。

打开一条进入项目详情。

### 项目详情

页头：名称、状态。结余小于 0 时有「超支」。认领了其中一笔善款时，那一行有「我的捐款」。未登录时这两处标记都不出现。项目没有封面，不展示封面图。其下是简介，然后是开始日期和受益人人数。登录且该项目包含自己时，「包含我」紧跟在受益人人数后面。善款合计、开销合计、结余在同一行均分宽度，不换行，也不超出页面。刚创建且尚无善款和开销时，三项金额都是 0，没有超支。

然后按这个顺序：

- 进展：纵向卡片。标题在左，日期在右，同一行。其下是正文和图片。多张图片一次只显示一张，点「下一张」切换。只有一张时不出现「下一张」。没有进展编号，也没有编辑和删除。默认只展示前 2 条。多于 2 条时，下方居中显示「查看更多进展」，每点一次再展示 2 条。已经多看过、且仍有未展示记录时，「收起更多进展」与「查看更多进展」并排，收起在左。全部展示后只留下「收起更多进展」。没有时说明暂无进展。
- 善款：该项目的有效绑定。卡片见上一节，不重复项目名称。没有时显示「帮助来源待补充」。
- 开销：未作废。卡片类别在左，开销日期在右，金额和说明在下。没有时说明暂无开销。

善款和开销按第 2 节默认展示 5 条，每次再展示 5 条，并能收起。不展示受益人姓名和唯一 ID、善款备注、平台用户 ID、订单编号、身份手机号、已作废开销、已解除绑定，也没有管理操作按钮。已删除的进展不在此页。

从「项目」进入，返回回到「项目」并保留筛选。从「善款」点进项目，返回回到「善款」。从「我的」的包含自己的项目进入，返回回到「我的」。

### 「善款」

全部未作废善款，按捐款日期倒序。查询只有绑定状态，按钮为「全部」「已绑定」「未绑定」。不按平台查询，捐款日期不在这一侧。卡片见第 2 节。没有记录时说明当前没有公开的捐款记录，筛选仍在。已作废善款不在此页。

### 「我的」未登录

只有用户登录。页面不显示「登录」标题，登录内容在页面里上下居中。两个标签：「密码登录」「验证码登录」。打开时停在「密码登录」。

密码登录：手机号、密码、「登录」。手机号有对应的密码提示时，提示文字紧挨在「密码」右侧、密码输入框上方，不靠行尾；清空手机号或该号码没有提示时不显示。

验证码登录：手机号、获取验证码、验证码、「登录」。验证码已发送时说明 5 分钟内有效。同一手机号 1 小时内已发送 5 次时，说明达到上限，表单仍在。验证码错误或过期时停在表单并说明。尚未设置密码或密码不正确时，停在密码登录并说明，可改用验证码或重置密码。

「重置密码」固定在页面底部，居中，没有边框。密码登录和验证码登录都有。

没有捐赠身份、受益人和包含自己的项目，也没有「进入后台」。

### 重置密码

从登录页的「重置密码」进入。返回在左上。手机号、获取验证码、验证码、新密码、确认新密码、密码提示。「非必填」紧挨在「密码提示」右侧，不靠行尾，可以留空。「确认重置」在最右。新密码至少 8 位，两次须一致。成功后回到登录页，说明请用新密码登录，页面仍默认密码登录；这次填写的提示紧挨在「密码」右侧，不靠行尾，留空则不显示。失败则停在本页并说明原因。密码提示留空不影响重置。

### 「我的」已登录

页头靠右并排，不换行：脱敏登录手机号、「退出」。手机号是启用管理员时，另有「进入后台」，排在最右，点击后离开用户端进入项目列表。未录入或已停用时没有这个按钮。

同一页从上到下三块，不另开页面，也不按平台、名称或状态筛选：

- 我的捐赠身份列表。金额汇总为累计捐款金额、已进入项目的金额、尚未安排的金额。每张卡片同一行：捐赠身份名称、匿名或不匿名、捐赠平台。操作靠右，从左到右是解除绑定、修改对外资料、打开。不统计已认领身份数，不展示平台用户 ID 和备注，列表下方也不显示「共 N 条」。没有认领时三项金额为 0，并说明当前没有已认领的捐赠身份。
- 「绑定捐赠身份」是居中、没有边框的可操作文字，紧接在捐赠身份列表下方。点击后在当前页展开绑定表单，文字变为「收起绑定捐赠身份」。再点则收起表单，文字变回「绑定捐赠身份」。
- 我的受益。包含自己的项目不另写「受益项目」。与公开项目三行相同，名称后只有状态，按开始日期倒序。没有时说明「暂时没有包含我的项目」。未绑定只说明绑定后才会列出，不展示项目。列表下方不显示「共 N 条」，最后一条下方也不画线。「绑定受益人身份」是居中、没有边框的可操作文字，在项目列表上方。未绑定时才显示。点击后在当前页展开姓名和唯一 ID，文字变为「收起绑定受益人身份」。再点则收起，文字变回「绑定受益人身份」。提交绑定后表单收起，姓名和脱敏号码改到项目列表上方，不显示「唯一 ID」字样。点击号码看完整值。解除绑定靠右。不显示其他受益人。绑定成功后不再显示「绑定受益人身份」。

绑定捐赠身份不另开页面。两个输入：平台（微信支付或支付宝）、平台用户 ID。提交前不列出身份。主按钮是「提交绑定」。找到且尚未认领时，提交后表单收起，该身份出现在捐赠身份中。不展示笔数、金额合计和备注。没有匹配，或该身份没有未作废善款时，提示「未找到对应捐款记录」。已经认领时，提示已经绑定。

解除绑定先弹出确认，说明只影响当前手机号。确认后留在「我的」；取消则不解除。解除受益人绑定后，项目不再列出，「绑定受益人身份」重新出现并保持收起。

绑定受益人时，姓名或唯一 ID 对不上，提示「未找到匹配的受益人信息」，不说明是哪一项不对。绑定成功后不再显示「绑定受益人身份」。

### 捐款列表

从捐赠身份打开。「我的」仍高亮。顶部是这条捐赠身份：公开称呼在左，是否匿名紧跟名称，平台在下方。其下绑定状态用按钮「全部」「已绑定」「未绑定」，改完即查。每笔未作废善款一张卡片，只显示捐款金额、绑定状态、捐款日期和绑定项目。已绑定的项目名称可点进项目；未绑定为「尚未安排到具体项目」。不展示公开称呼、个人说明、备注、平台用户 ID、订单编号。没有修改资料、解除绑定、作废和改金额。返回回到「我的」。

### 修改身份

可改是否匿名、对外展示名、个人说明。平台、平台用户 ID、手机号是不可改的文字。个人说明不超过 200 字。保存或取消都回到「我的」。

## 4. 管理端

桌面用表格，移动用卡片。各列表的「清除」只在桌面端。手机号和受益人唯一 ID 默认保留前 3 位和后 4 位，点击后再看完整值。平台用户 ID 完整展示。

### 项目列表

默认按开始日期倒序。桌面列：项目编号、名称、状态、开始日期、善款、开销、结余、受益人，操作是「删除」「打开」，打开在最右。查询：项目编号、项目名称、状态。状态含「全部」「进行中」「已完成」「已关闭」和只看超支。移动卡片见第 2 节，只展示项目名称和状态，改完即查。卡片下方靠右同样是「删除」「打开」。页上有「新建项目」。点「删除」弹出确认，写明项目名称。确认后该项目从管理端和公开项目列表消失；取消则留在列表。

### 新建项目

字段：项目名称（不超过 50 字）、项目简介、开始日期、受益人。项目没有封面，不上传图片。受益人按姓名或唯一 ID 查询后添加，至少一名。桌面端和移动端都先显示居中可操作文字「添加受益人」，点击后展开查询，文字变为「收起添加受益人」，再点收起。展开后，尚未加入本项目的档案按更新日期倒序分页，也可按姓名或唯一 ID 查询。空条件同样分页。桌面用表格，默认每页 10 条，底栏有共 N 条和翻页。移动用卡片，每页固定 5 条，显示共 N 条和第几页、总页数，并有上一页、下一页。移动端已添加的卡片和查询结果卡片上，脱敏唯一 ID 都紧跟在姓名后面，同一行。查询结果卡片之间不画分隔线。桌面端已添加的受益人和查询结果都用表格，列为姓名、唯一 ID、备注、操作。已添加的一次列全，不分页。移动端卡片在姓名和唯一 ID 下方展示备注。没有备注时显示「无」。移动端多名已添加的人之间仍有分隔线，最后一名和「添加受益人」之间没有线。「保存」上方有一条分隔线。没有命中时提供「前往新建受益人」。未添加就保存，提示「请至少选择一名受益人」。

从受益人详情进入时，当前这位已经添加且不能移除。取消回到进入前的页面。保存后进入新项目详情，状态为进行中，三项金额为 0。

### 项目详情

页头同一行：项目编号居左，「返回列表」居右。其下是名称、状态。结余小于 0 时有「超支」。项目没有封面。其下是简介、开始日期。善款合计、开销合计、结余在同一行均分宽度，不换行，也不超出页面。

页头操作，桌面和移动相同。进行中时从左到右：编辑、标记完成、标记关闭。已完成或已关闭时不出现「编辑」，改为「改回进行中」。「追加受益人」在「受益人」同一行居右，仅进行中出现。「发布进展」在「进展」同一行居右，仅进行中出现。「绑定善款」在「善款」同一行居右。「登记开销」在「开销」同一行居右。解除和作废仍在各条记录上。受益人的「移除」只在进行中出现。已有进展的编辑和删除也仍在。

然后：

- 受益人。桌面端和移动端标题都是「受益人」，进行中时标题同一行右侧是「追加受益人」。列出该项目全部受益人，不查询、不分页。姓名、脱敏唯一 ID（点击看完整）、备注。进行中时另有「移除」。已完成或已关闭不出现「移除」，要先改回进行中。桌面用表格，列为姓名、唯一 ID、备注，进行中再加操作。移动用卡片：第一行是受益人姓名和脱敏唯一 ID，同一行；第二行是受益人备注。没有备注时显示「无」。只剩一名时移除会提示至少保留一名。
- 进展。标题同一行右侧是「发布进展」，仅进行中出现。桌面端全部展示，不折叠。纵向卡片横向排列，放不下就换行，不出现横向滚动条。卡片内标题在左、日期在右，同一行。其下是编号、正文和图片。没有图片时不留空位。多张图片一次只显示一张，点「下一张」切到后一张，到最后一张后再点回到第一张。只有一张时不出现「下一张」。操作只有「编辑」和「删除」，删除在最右。移动端默认只展示前 2 条。多于 2 条时，下方居中显示「查看更多进展」，每点一次再展示 2 条。已经多看过、且仍有未展示记录时，「收起更多进展」与「查看更多进展」并排，收起在左。全部展示后只留下「收起更多进展」。卡片内容与桌面相同：标题在左、日期在右，其下是编号、正文和图片。多张图片一次只显示一张，点「下一张」切换。操作只有编辑和删除。删除后该条从列表消失。
- 善款。标题同一行右侧是「绑定善款」。有效绑定按捐款日期倒序。操作从左到右是打开身份、作废、解除绑定，解除绑定在最右。没有「详情」。桌面端全部展示，不折叠。表格列：善款编号、金额、捐款身份姓名、日期、捐款平台、订单编号、操作。移动端按第 2 节默认展示 5 条，每次再展示 5 条，并能收起。卡片第一行是金额和捐款身份姓名，日期在右；第二行是善款编号；第三行是捐款平台和订单编号。
- 开销。标题同一行右侧是「登记开销」。含已作废，并标明已作废、不计入合计。桌面端全部展示，不折叠。桌面表格列：开销编号、日期、类别、金额、说明、状态。移动端按第 2 节默认展示 5 条，每次再展示 5 条，并能收起。

### 编辑项目

可改名称、简介、开始日期。受益人的追加和移除不在本页。已完成或已关闭要先改回进行中才能进入。

### 追加受益人

只在进行中的项目详情进入。已完成或已关闭没有「追加受益人」，要先改回进行中。只在尚未关联到本项目的档案中查找，按更新日期倒序分页。打开时第一页是最近更新的记录，显示姓名、脱敏唯一 ID 和备注，可添加多名。也可按姓名或唯一 ID 查询，结果同样按更新时间倒序分页。桌面用表格，默认每页 10 条。移动用卡片，每页固定 5 条，显示共 N 条和第几页、总页数，并有上一页、下一页。已在项目中的不出现。

### 选择未绑定善款

从项目详情「绑定善款」进入。只在未作废且未绑定的善款里找，按捐款日期倒序分页。打开时就列出，空条件仍是这份名单。也可按订单编号、善款编号或平台用户 ID 查询，结果同样分页。桌面用表格，默认每页 10 条。移动用卡片，每页固定 5 条，显示共 N 条和第几页、总页数，「上一页」「下一页」靠页面右侧。命中后显示编号、订单编号、平台、平台用户 ID、金额、捐款日期、当前展示名。没有金额输入框。没有可选善款时说明当前没有未绑定善款。

### 登记开销、编辑开销

登记字段：开销日期、类别（物资采购、交通食宿、人员补贴、其他）、金额、说明。不填写分摊对象。大于结余时仍然可以保存，回到详情后标记超支。编辑可改这四项。已作废的不能再改。作废不填原因，确认后该条留在管理端列表，状态为已作废。

### 发布进展

字段：日期、标题、正文、图片（选填）。已完成或已关闭的详情没有「发布进展」。已有进展可以编辑这些字段，也可以删除。删除后管理端和公开页面都不再展示。

### 善款列表

默认按捐款日期倒序。捐款身份姓名是身份当前的公开称呼。没有项目时为「—」，没有备注时为「无」。

桌面表格列：善款编号、金额、捐款身份姓名、日期、状态、项目。默认每条一行，单元格和操作都不换行。捐款平台、订单编号、备注默认折叠，点「展开」后显示在该行下方，再点「收起」收回。操作从左到右是打开身份、作废，作废在最右。已作废的记录不显示作废。

筛选直接展示：订单编号、捐款身份平台 ID、捐款身份姓名/手机号、绑定状态下拉框。捐款日期起、捐款日期止收在「更多条件」。桌面点「查询」后生效。移动端改完即查，不显示「清除」和「查询」。

移动卡片第一行是金额和捐款身份姓名，日期在右；第二行是善款编号；第三行是状态和项目。捐款平台、订单编号、备注默认折叠，点「展开」后显示，再点「收起」收回。展开后不标注字段名：第一行是捐款平台和订单编号，第二行是备注。没有备注时显示「无」。操作从左到右是打开身份、作废，作废在最右。已作废的记录不显示作废。

页上操作：新建善款、批量导入、批量作废。

### 单笔录入

先按平台用户 ID、手机号或对外展示名查询已有身份。查询前和空条件不列出全部身份。桌面端这三项查询条件都直接展示，不收进「更多条件」。命中后显示平台、平台用户 ID、公开称呼和完整手机号，不脱敏，每条一行。点「添加」后，已选身份同样展示完整手机号，排成一行。没有匹配时不能保存，并提供去创建捐款身份。

再填金额、捐款日期、订单编号、备注。桌面端订单编号独占一行，金额和捐款日期并排，备注独占一行。移动端在查询捐款身份和录入捐款信息之间有分割线，四项各占一行，顺序为订单编号、金额、捐款日期、备注。本页不出现平台、平台用户 ID、是否匿名、对外展示名、个人说明和手机号的填写项。

### 导入与批量作废

两条路径都是：下载 Excel 模板、上传 `.xlsx`、预览、确认写入。单次最多 500 行，超出时说明超出上限，不逐行写入。只读第一个工作表，第一行是表头。平台用户 ID、手机号、订单编号按文本填写。

导入模板列：平台、平台用户 ID、对外展示名、手机号、金额、捐款日期、订单编号。预览每一行标明将新建身份、展示名将更新、展示名本次不覆盖，或该行错误。任一行失败时「确认写入」不可用，并列出失败行号和原因，原文件不保存。全部通过后进入结果页，说明写入行数和新增善款笔数，并把原 Excel 存入导入目录。

作废模板列：订单编号、作废原因。预览标明将作废；已绑定的另外标明先解除项目绑定。已作废的行标为不能再次作废。任一行失败时不保存文件。全部通过后，结果页说明本批已作废的行数，并把原 Excel 存入作废目录。

### 导入文档

侧栏在「管理员」之前，「捐款身份」在「受益人」之下。页面分成「导入成功」和「作废成功」两个目录。只列出整批成功的 Excel。每一条显示文件名、时间和行数，「下载」在右。桌面用表格，移动用卡片。失败的批次不出现。

### 作废善款

从善款列表或项目详情进入。先展示这笔善款：善款编号、订单编号、金额、捐款日期、绑定状态、当前项目、捐款平台、平台用户 ID、是否匿名、对外展示名、身份手机号（完整号码）、用户已修改。个人说明和备注各占一行。桌面端前面各项两列排列，移动端每项一行。已绑定的显示项目名称和项目编号；未绑定为「尚未绑定」。其下填写作废原因。已绑定的说明：确认后先解除项目绑定，再改为已作废。原因为空不能确认。确认或取消后回到进入前的页面。已作废时仍展示上述信息，并说明不能再次作废。

### 捐款身份列表

每一行：平台、平台用户 ID、当前展示名、当前是否匿名、手机号（脱敏）、用户已修改、名下未作废善款笔数。尚无善款的身份也在。查询：平台、平台用户 ID、手机号。移动端展示平台。页上有「创建捐款身份」。

### 创建捐款身份

字段：平台、平台用户 ID、是否匿名（默认「是」）、对外展示名、个人说明、手机号。平台和平台用户 ID 创建后不能改。保存后进入新身份详情。

### 身份详情

展示：平台、平台用户 ID、是否匿名、对外展示名、个人说明、手机号（脱敏）、「用户已修改」、修改时间、名下善款（订单编号、善款编号、金额、状态、日期）。名下善款不能打开某一笔。还没有善款时说明尚未录入。

无论用户是否已修改，都可以更正匿名、对外展示名、个人说明。保存后「用户已修改」为否，修改时间清空。手机号不在更正页修改。

### 受益人列表

桌面每一行：姓名、脱敏唯一 ID、备注，「打开」在最右。查询：姓名、唯一 ID。移动卡片第一行是受益人姓名和脱敏唯一 ID，同一行；第二行是受益人备注。没有备注时显示「无」。点击唯一 ID 看完整号码。「打开」在卡片下方靠右。页上有「新建受益人」。

### 新建受益人

字段：姓名、唯一 ID、备注。唯一 ID 与已有档案重复或必填为空时停在本页。

### 受益人详情

展示：姓名、唯一 ID（脱敏，点击看完整）、备注、已加入的项目。项目与项目列表的移动卡片相同，只含当前有效关联。操作：创建项目、打开项目。还没有人用用户端绑定时，项目仍然列在这里。

### 管理员名单

只读。每一行：姓名、手机号（脱敏，点击看完整）、状态（启用或停用）。查询：姓名、手机号、状态。移动端展示姓名和状态。页面说明新增和停用在数据库中完成。没有新增、编辑、停用、删除。
