# 微光原型图描述

这份文档只写画面：每个页面上有哪些字、什么顺序、空的时候显示什么、按钮在哪。

能不能做、数字怎么算，看《产品需求文档》。点完走到哪一页，看《用户用例手册》。三份对不上时，按需求文档开头的顺序采信。

查询草稿、分页条、卡片和折叠文字，以 `.cursor/rules/prototype-layout.mdc` 为准。下面只写每个页面用了哪一种。

公开页面上怎么称呼捐款人，按《产品需求文档》第 6.1 节。本文件第 2 节只写这个称呼出现在卡片的哪一行。

## 1. 两套外壳

### 用户端

用户端是宽 360px 的手机。

- 页顶「微光」居中。
- 底部三个标签一直在：「项目」「善款」「我的」。
- 打开时停在「项目」。当前标签高亮。
- 列表、详情和登录过程中，标签不消失。
- 返回在左上。
- 内容限制在手机宽度内。不出现横向滚动条。一行放不下就换行。

### 管理端

管理端有桌面和移动两种布局。

桌面用侧栏，七项并列：

1. 项目
2. 善款
3. 受益人
4. 捐款身份
5. 导入文档
6. 作废善款
7. 管理员

移动端从宽度 360px 起。底部是「项目」「善款」「受益人」「其他」。

「其他」默认收起。展开后是「捐款身份」「导入文档」「作废善款」和「管理员」。

从用户端「我的」点「进入后台」，首先进入项目列表。

返回在左上。操作按钮靠右。主操作在最右。

桌面表格和底栏都限制在页面宽度内。放不下时换行。不出现横向滚动条。

## 2. 反复出现的样子

### 公开称呼

| 身份情况 | 称呼 |
| --- | --- |
| 匿名 | 匿名捐款人 |
| 未匿名，对外展示名有内容 | 对外展示名 |
| 未匿名，对外展示名为空 | 「{平台}捐款人」 |

用户端「善款」页不展示个人说明。项目详情里的善款也不展示个人说明。

### 公开项目：一条三行

- 第一行：项目名称居左。状态标签紧跟名称。开始日期居右。用户侧只有状态，不显示「超支」。
- 第二行：善款合计、开销合计。
- 第三行：「x 名受益人」。

结余和项目编号不在这一侧。

### 管理端项目：移动卡片

和公开三行相同，并多出管理字段。

结余小于 0 时，「超支」紧跟状态。项目编号在名称下方，靠左。第二行另有结余。

桌面端改用表格。

### 公开善款：一张卡片

- 第一行：公开称呼在左。捐款日期在右。
- 其下：金额、平台。
- 不展示个人说明，也不展示状态。

项目详情里的「善款」不再重复项目名称。

善款捐赠明细在下方增加项目。已经安排的，显示项目名称，可以点进项目。尚未安排为「尚未安排到具体项目」，不能点。

某一身份的捐款列表不用这张卡片。

### 详情里记录太多时

用户端项目详情，以及管理端移动端的进展、善款、开销，都不筛选、不分页。都按日期倒序。

- 进展默认只展示前 2 条。每次再展示 2 条。
- 善款和开销默认只展示前 5 条。每次再展示 5 条。

多于默认条数时，下方居中显示没有边框的「查看更多」，后面加上该段标题。

已经多看过、且仍有未展示记录时，「收起更多」和「查看更多」并排居中。收起在左。

全部展示后，只留下「收起更多」。点它回到默认条数。

管理端桌面这三段全部展示，不折叠。

### 列表查询

桌面端：

- 主键、名称、分类直接展示。
- 时间和其他字段收在「更多条件」，默认折叠。
- 点「查询」才生效，并从第 1 页重新取。
- 「清除」在左，「查询」在右。
- 用表格。每页可选 10、20、50。
- 底栏一行：共 N 条、N条/页、上一页、附近页码和首页末页、下一页、前往页码。
- 总数为 0 时，只显示「共 0 条」。

移动端和用户端：

- 展示名称和分类。
- 分类的选项用按钮平铺。同一时间只选中一项。改完即查。
- 没有名称和分类时，改为展示主键。同样改完即查。
- 不显示「清除」和「查询」。
- 用卡片。滑到底，按每页 10 条继续加载。
- 底部只显示共 N 条。

## 3. 用户端

### 「项目」

查询项是项目名称。状态按钮为「全部」「进行中」「已完成」「已关闭」。

默认按开始日期倒序。每一条用公开项目三行。

没有项目时，说明当前没有公开项目。

没有新建、编辑、绑定、作废。受益人只有人数。

打开一条，进入项目详情。

### 项目详情

页头是名称和状态。结余小于 0 时有「超支」。

认领了其中一笔善款时，那一行有「我的捐款」。未登录时，这两处标记都不出现。

项目没有封面，不展示封面图。其下是简介，然后是开始日期和受益人人数。

登录且该项目包含自己时，「包含我」紧跟在受益人人数后面。

善款合计、开销合计、结余在同一行均分宽度。不换行，也不超出页面。

刚创建且还没有善款和开销时，三项金额都是 0，没有超支。

然后按这个顺序：进展、善款、开销。

进展是纵向卡片。

- 标题在左，日期在右，同一行。其下是正文和图片。
- 多张图片一次只显示一张。点「下一张」切换。只有一张时不出现「下一张」。
- 没有进展编号，也没有编辑和删除。
- 默认只展示前 2 条。多于 2 条时，下方居中显示「查看更多进展」，每点一次再展示 2 条。
- 已经多看过、且仍有未展示记录时，「收起更多进展」与「查看更多进展」并排，收起在左。
- 全部展示后只留下「收起更多进展」。没有时说明暂无进展。

善款是当前挂在该项目上的记录。卡片见上一节，不重复项目名称。没有时显示「帮助来源待补充」。

开销只列出还在的记录。卡片上类别在左，开销日期在右，金额和说明在下。没有时说明暂无开销。

善款和开销按第 2 节默认展示 5 条，每次再展示 5 条，并能收起。

不展示这些内容：受益人姓名和唯一 ID、善款备注、平台用户 ID、订单编号、身份手机号、已删除的开销。也没有管理操作按钮。已删除的进展不在此页。善款只列出项目就是该项目的记录。

返回去哪，取决于从哪进来：

- 从「项目」进入，返回回到「项目」，并保留筛选。
- 从「善款」点进项目，返回回到「善款」。
- 从「我的」里包含自己的项目进入，返回回到「我的」。

### 「善款」

这里列出还在的善款，按捐款日期倒序。作废后的记录在管理端「作废善款」，不在此页。

查询只有「项目」。按钮为「全部」「已安排」「尚未安排」。不按平台查询。捐款日期不在这一侧。

卡片见第 2 节。没有记录时，说明当前没有公开的捐款记录。筛选仍在。

### 「我的」未登录

这里只有用户登录。页面不显示「登录」标题。登录内容在页面里上下居中。

两个标签：「密码登录」「验证码登录」。打开时停在「密码登录」。

密码登录有手机号、密码和「登录」。手机号有对应的密码提示时，提示文字紧挨在「密码」右侧、密码输入框上方，不靠行尾。清空手机号，或该号码没有提示时，不显示提示。

验证码登录有手机号、获取验证码、验证码和「登录」。验证码已发送时，说明 5 分钟内有效。同一手机号 1 小时内已发送 5 次时，说明达到上限。表单仍在。验证码错误或过期时，停在表单并说明。

尚未设置密码，或密码不正确时，停在密码登录并说明。可以改用验证码，或重置密码。

「重置密码」固定在页面底部，居中，没有边框。密码登录和验证码登录都有它。

没有捐赠身份、受益人和包含自己的项目，也没有「进入后台」。

### 重置密码

从登录页的「重置密码」进入。返回在左上。

字段：手机号、获取验证码、验证码、新密码、确认新密码、密码提示。「非必填」紧挨在「密码提示」右侧，不靠行尾。可以留空。「确认重置」在最右。

新密码至少 8 位。两次须一致。

成功后回到登录页，说明请用新密码登录。页面仍默认密码登录。这次填写的提示紧挨在「密码」右侧，不靠行尾。留空则不显示。

失败则停在本页，并说明原因。密码提示留空不影响重置。

### 「我的」已登录

页头靠右并排，不换行：脱敏登录手机号、「退出」。

手机号还在管理员记录里时，另有「进入后台」，排在最右。点击后离开用户端，进入项目列表。未录入，或记录已删除时，没有这个按钮。

同一页从上到下三块。不另开页面，也不按平台、名称或状态筛选。

- 我的捐赠身份列表。金额汇总为累计捐款金额、已进入项目的金额、尚未安排的金额。每张卡片同一行：捐赠身份名称、匿名或不匿名、捐赠平台。操作靠右，从左到右是解除绑定、修改对外资料、打开。不统计已认领身份数。不展示平台用户 ID 和备注。列表下方也不显示「共 N 条」。没有认领时，三项金额为 0，并说明当前没有已认领的捐赠身份。
- 「绑定捐赠身份」是居中、没有边框的可操作文字，紧接在捐赠身份列表下方。点击后在当前页展开绑定表单，文字变为「收起绑定捐赠身份」。再点则收起表单，文字变回「绑定捐赠身份」。
- 我的受益。包含自己的项目不另写「受益项目」。与公开项目三行相同。名称后只有状态。按开始日期倒序。没有时说明「暂时没有包含我的项目」。
- 未绑定只说明绑定后才会列出，不展示项目。列表下方不显示「共 N 条」。最后一条下方也不画线。
- 「绑定受益人身份」是居中、没有边框的可操作文字，在项目列表上方。未绑定时才显示。点击后在当前页展开姓名和唯一 ID，文字变为「收起绑定受益人身份」。再点则收起，文字变回「绑定受益人身份」。
- 提交绑定后表单收起。姓名和打码号码改到项目列表上方。不显示「唯一 ID」字样。点击号码看完整值。解除绑定靠右。不显示其他受益人。绑定成功后不再显示「绑定受益人身份」。

绑定捐赠身份不另开页面。两个输入：平台（微信支付或支付宝）、平台用户 ID。提交前不列出身份。主按钮是「提交绑定」。

找到且尚未认领时，提交后表单收起，该身份出现在捐赠身份中。不展示笔数、金额合计和备注。

没有匹配，或该身份没有善款时，提示「未找到对应捐款记录」。已经认领时，提示已经绑定。

解除绑定先弹出确认，说明只影响当前手机号。确认后留在「我的」。取消则不解除。

解除受益人绑定后，项目不再列出。「绑定受益人身份」重新出现，并保持收起。

绑定受益人时，姓名或唯一 ID 对不上，提示「未找到匹配的受益人信息」。不说明是哪一项不对。绑定成功后不再显示「绑定受益人身份」。

### 捐款列表

从捐赠身份打开。「我的」仍高亮。

顶部是这条捐赠身份：公开称呼在左，是否匿名紧跟名称，平台在下方。

其下用按钮选项目：「全部」「已安排」「尚未安排」。改完即查。

每笔善款一张卡片。只显示捐款金额、捐款日期和项目。已经安排的项目名称可点进项目。尚未安排为「尚未安排到具体项目」。

不展示公开称呼、个人说明、备注、平台用户 ID、订单编号。没有修改资料、解除绑定、作废和改金额。

返回回到「我的」。

### 修改身份

可以改是否匿名、对外展示名、个人说明。

平台、平台用户 ID、手机号是不可改的文字。个人说明不超过 200 字。

保存或取消都回到「我的」。

## 4. 管理端

桌面用表格，移动用卡片。各列表的「清除」只在桌面端。

手机号和受益人唯一 ID 默认保留前 3 位和后 4 位。点击后再看完整值。平台用户 ID 完整展示。

### 项目列表

默认按开始日期倒序。

桌面列：项目编号、名称、状态、开始日期、善款、开销、结余、受益人。操作只有「打开」。

查询：项目编号、项目名称、状态。状态含「全部」「进行中」「已完成」「已关闭」，以及只看超支。

移动卡片见第 2 节。只展示项目名称和状态，改完即查。卡片下方靠右只有「打开」。

页上有「新建项目」。

### 新建项目

字段：项目名称（不超过 50 字）、项目简介、开始日期、受益人。项目没有封面，不上传图片。

受益人按姓名或唯一 ID 查询后添加，至少一名。

桌面端和移动端都先显示居中可操作文字「添加受益人」。点击后展开查询，文字变为「收起添加受益人」。再点收起。

展开后：

- 尚未加入本项目的档案按更新日期倒序分页。
- 也可按姓名或唯一 ID 查询。
- 空条件同样分页。
- 桌面用表格，默认每页 10 条。底栏有共 N 条和翻页。
- 移动用卡片，每页固定 5 条。显示共 N 条和第几页、总页数，并有上一页、下一页。
- 移动端已添加的卡片和查询结果卡片上，脱敏唯一 ID 都紧跟在姓名后面，同一行。
- 查询结果卡片之间不画分隔线。
- 桌面端已添加的受益人和查询结果都用表格。列是姓名、唯一 ID、备注、操作。已添加的一次列全，不分页。
- 移动端卡片在姓名和唯一 ID 下方展示备注。没有备注时显示「无」。
- 移动端多名已添加的人之间仍有分隔线。最后一名和「添加受益人」之间没有线。
- 「保存」上方有一条分隔线。

没有命中时，提供「前往新建受益人」。未添加就保存，提示「请至少选择一名受益人」。

从受益人详情进入时，当前这位已经添加，且不能移除。取消回到进入前的页面。保存后进入新项目详情。状态为进行中。三项金额为 0。

### 项目详情

页头同一行：项目编号居左，「返回列表」居右。其下是名称、状态。结余小于 0 时有「超支」。项目没有封面。其下是简介、开始日期。

善款合计、开销合计、结余在同一行均分宽度。不换行，也不超出页面。

页头操作，桌面和移动相同。

- 进行中时，从左到右：编辑、标记完成、标记关闭。
- 已完成或已关闭时，不出现「编辑」，改为「改回进行中」。
- 「追加受益人」在「受益人」同一行居右，仅进行中出现。
- 「发布进展」在「进展」同一行居右，仅进行中出现。
- 「绑定善款」在「善款」同一行居右。
- 「登记开销」在「开销」同一行居右。
- 解除和作废仍在各条记录上。
- 受益人的「移除」只在进行中出现。
- 已有进展的编辑和删除也仍在。

然后四段：

**受益人**

桌面端和移动端标题都是「受益人」。进行中时，标题同一行右侧是「追加受益人」。

列出该项目全部受益人。不查询，不分页。显示姓名、脱敏唯一 ID（点击看完整）、备注。进行中时另有「移除」。已完成或已关闭不出现「移除」，要先改回进行中。

桌面用表格。列是姓名、唯一 ID、备注。进行中再加操作。

移动用卡片。第一行是受益人姓名和脱敏唯一 ID，同一行。第二行是受益人备注。没有备注时显示「无」。

只剩一名时，移除会提示至少保留一名。

**进展**

标题同一行右侧是「发布进展」，仅进行中出现。

桌面端全部展示，不折叠。纵向卡片横向排列。放不下就换行。不出现横向滚动条。

卡片内标题在左、日期在右，同一行。其下是编号、正文和图片。没有图片时不留空位。多张图片一次只显示一张。点「下一张」切到后一张。到最后一张后再点，回到第一张。只有一张时不出现「下一张」。操作只有「编辑」和「删除」，删除在最右。

移动端默认只展示前 2 条。多于 2 条时，下方居中显示「查看更多进展」，每点一次再展示 2 条。已经多看过、且仍有未展示记录时，「收起更多进展」与「查看更多进展」并排，收起在左。全部展示后只留下「收起更多进展」。

移动卡片内容与桌面相同。删除后该条从列表消失。

**善款**

标题同一行右侧是「绑定善款」。当前挂在本项目上的善款，按捐款日期倒序。

操作从左到右是打开身份、作废、解除绑定。解除绑定在最右。没有「详情」。

桌面端全部展示，不折叠。表格列：善款编号、金额、捐款身份姓名、日期、捐款平台、订单编号、操作。

大于结余时仍然可以保存。回到详情后标记超支。

字段：日期、标题、正文、图片（选填）。

已完成或已关闭的详情没有「发布进展」。已有进展可以编辑这些字段，也可以删除。删除后，管理端和公开页面都不再展示。
